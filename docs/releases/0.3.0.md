No compilation, Visual Studio or SDK installation is needed. The unsigned ZIP includes the plugin, English/Czech language modules and English/Czech README and PILOT guides.

## Changes since 0.2.1

- **Modeless synchronization window:** keep working in Samandarin's panels while the plugin is open, comparing or transferring files. Reopening the plugin activates the existing window.
- **Native transfer-progress window:** source/target paths, progress, transferred data, speed and estimated time, with Minimize, Pause/Resume, a per-batch speed limit and Cancel. Completed changes remain after cancellation.
- **Stored originals:** a read-only session browser showing original/saved paths, sizes, recovery-copy availability and recorded operation results. Copy paths, open directories and refresh records. No automatic restore or backup cleanup.
- **CSV and text exports:** export comparison rows and recorded operation results, including hidden/skipped rows, filters, recovery paths and errors. Recorded results remain distinct from current filesystem state.
- Smaller Release binaries, clearer English/Czech UI and verified safe shutdown/forced unload in modeless mode.

## Install or update

Close all host instances using the plugin. Extract the complete `dirsync` directory into `plugins` beside `salamand.exe`, preserving `dirsync/lang`. Register `dirsync.spl` through Plugins Manager → Add… only if it is not already registered.

For an update from 0.2.1, back up the host configuration and optionally export profiles, then replace the existing plugin files in place. Keep configuration and recovery directories; do not remove/re-add the plugin. Settings, profiles and the last selected profile are preserved. Read `PILOT.md` or `PILOT.cs.md` before testing.

## Validation and limits

Clean installation and updating from the published 0.2.1 package were verified in an isolated Samandarin 0.16 x64 developer build, including English/Czech loading and registration/settings/profiles across restarts. All 13 saved plugin values remained identical after the upgrade. Local x64 tests cover operations, exports, lifecycle and both language resources; Win32/ARM64 builds are compile checks, not runtime validation.

**Local NTFS alpha only: SMB remains untested and the SDK is unchanged.** No automatic rollback, recovery replay or host transfer-queue integration. The lowest tested host versions remain 0.15.1 in user testing and unreleased 0.16 in automated testing of a custom developer build.
