## Changes since 0.3.0

- **Interactive operation errors:** Retry / Skip / Skip all / Cancel for supported failures during copying, saving originals, overwrites and asymmetric deletion. Independent work can continue after Skip; unsaved originals and retained children protect dependent operations and parent directories. A remembered **Stop at first error** option restores immediate stopping. Fatal errors still end the remaining batch.
- **Compact synchronization confirmation:** select copy directions, allow or exclude overwrites, select asymmetric deletion, review recovery settings and open read-only **Details…**. Separate commands and exports remain on the Synchronize arrow menu. Commands execute visible eligible proposals, not only highlighted rows.
- **Remembered transfer speed limit** across operations and restarts, with smaller I/O blocks for smoother low-speed transfers. Progress-window Cancel/Close and main-window Close during file operations ask before cancelling. Completed changes remain; there is no automatic rollback.
- **Shared directory history** for both sides, confirmation before discarding manual proposals, clearer EN/CS dialogs, shortened long-path display and consistent progress-bar frames.
- More accurate summaries, stored-originals records and CSV/text exports for skipped, dependency-blocked, failed and unstarted operations.

## Install or update

Close all host instances using the plugin. Extract the complete `dirsync` directory into `plugins` beside `salamand.exe`, preserving `dirsync/lang`. Register `dirsync.spl` through Plugins Manager → Add… only if it is not already registered.

For an update from 0.3.0, back up the host configuration and optionally export profiles, then replace the existing plugin files in place. Keep configuration and recovery directories; do not remove/re-add the plugin. Settings, profiles and the last selected profile are preserved. Supported errors now ask by default; choose **Settings → Stop at first error** for the previous immediate-stop policy. A new configuration starts with **Keep originals OFF** until a recovery directory is configured; an existing saved choice is retained. Read `PILOT.md` or `PILOT.cs.md` before testing.

## Validation and limits

Clean installation and updating from the published 0.3.0 package were verified in an isolated Samandarin 0.16 x64 developer build, including English/Czech loading, registration after restart, settings and profiles. All 13 old settings and both Unicode profiles were preserved; all 17 new settings remained identical across language restarts. The final distribution passed 86 independent checks. The release package retains the same tested binary modules.

Local NTFS verification also covered mixed/error/Stop/Close outcomes and exports, recovery records, host shutdown/forced unload with an open error question, and actual disk exhaustion on an isolated NTFS VHD. Win32/ARM64 builds are compile checks, not runtime validation.

**Local NTFS alpha only: SMB remains untested and the SDK is unchanged.** No automatic rollback, recovery replay, backup cleanup or host transfer-queue integration. Comparison by content does not compare ADS. Large-list performance and cross-monitor DPI transitions remain limitations to investigate. The lowest tested host versions remain 0.15.1 in user testing and unreleased 0.16 in automated testing of a custom developer build.
